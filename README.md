# Connect Plinko

A browser Plinko / Connect Four hybrid game.

## Play

**https://gsbernstein.github.io/connect-plinko/**

## Local

Open `index.html` in a browser, or serve the repo root:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Hosting

This repo deploys to [GitHub Pages](https://pages.github.com/) via `.github/workflows/deploy-pages.yml` on every push to `master`.

If the site is not live yet, enable Pages once:

1. Repo **Settings → Pages**
2. **Source**: GitHub Actions
